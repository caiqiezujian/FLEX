## 共同约定

- 代码目录：/data/yb/Code/FLEX/FLEX-GSPO。
- 训练环境：/data/yb/vens/flex-gspo-online，在训练 Docker 内使用。
- 监控环境：/data/yb/vens/flex-tensorboard-host，在宿主机使用。
- 数据与训练输出分别使用两套目录，避免混用。
- prompt 由当前 flex_gspo/prompts.py 提供；旧数据格式不会恢复旧提示词。
- 对应 SFT 模型路径是示例，需替换为实际使用当前 prompt 训练的合并模型。
- 已经在训练时，不需要重装环境或重做数据；监控命令改为实际运行目录即可。
- 当前启动器仍限制四卡。八卡属于后续适配，不在文档中提供无法直接运行的命令。
- 本次只整理文档，没有修改奖励函数、训练代码或已有数据。
