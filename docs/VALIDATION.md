## 真实浏览器检查

启动 `--backend mock`，在浏览器中使用独立合成测试视频（30 秒彩条 + 440 Hz 测试音，不含真实语音），验证：

- 本地选择 MP4，并实际播放；WebVTT 字幕叠加可见。
- 浏览器 AudioWorklet → WebSocket → 服务端 FIFO → 三标签响应 → 右侧增量译文完整链路。
- 英→中与中→英切换后开启独立新会话；mock 文案明确说明不是真实翻译。
- 暂停时已接收音频停在暂停位置，没有把整个暂停时长发送为音频；恢复后继续顺序处理。
- 约 16.3 秒时手动结束：17 个处理轮次，最后不足一秒的真实尾音单独处理，模型输入补至 1 秒，源音频统计不增加至 17 秒。
- 播放自然结束后完成尾块处理，待处理量归零；可能有毫秒级媒体/采集调度差异，见协议说明。
- 下载 JSON 成功，包含语言方向、精确增量、每轮源音频区间、客户端接收时刻和当时的视频播放位置。
- 390 像素视口下左右两栏折叠为上下布局，无横向内容溢出；已恢复默认桌面视口。
- 麦克风模式页面切换可用；未启用用户设备真实录音。
- 运行会话期间浏览器未报告 JS error/warn。
